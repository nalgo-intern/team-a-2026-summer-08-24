# 食品品質判定 Flask アプリ

## 起動

```bash
cd main
uv sync
DEVICE=cpu uv run python app.py
```

ブラウザで http://127.0.0.1:5000 を開きます。

初回推論時にBiRefNetモデルを取得します。GPUを使う場合は `DEVICE=cuda` を指定してください。

Hugging Faceの警告を減らしてダウンロード制限を緩和する場合は、`HF_TOKEN`を環境変数に設定してください。未設定でもモデルが公開状態であれば動作します。

## 使い方

- 「画像ファイルを選択」から画像を選ぶ
- パソコンでは「Webカメラを起動」後、映像を確認して「撮影する」を押す
- スマートフォンでは「スマホで撮影」から端末の通常カメラを起動し、シャッターボタンで撮影する
- 「判定する」を押す

Webカメラはブラウザのカメラ使用許可が必要です。localhostではHTTPで利用できますが、外部サーバーへ公開する場合はHTTPSが必要です。

1枚の画像に写った食品1個を対象に、前景抽出と `Fresh / Rotten` 判定を行います。
